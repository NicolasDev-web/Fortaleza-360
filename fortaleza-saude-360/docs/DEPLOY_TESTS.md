# Qualidade e deploy
Comandos: `npm run lint`, `npm run typecheck`, `npm run build` e depois implementar `npm run test` (SDD). Teste manual desktop/mobile, teclado, contraste, carregamento lento, ausência de dados, erro de rede. Valide GeoJSON em produção: sem lat/lon trocada, geometrias válidas, ponto dentro do município (quando aplicável), UTF-8 e hashes. Antes de publicar: remover demo ou manter aviso persistente inequívoco; conferir atribuição de fontes, tiles, OpenStreetMap, licença de fontes e políticas de cache. Hosting preferencial Vercel com limites gratuitos; gasto e disponibilidade de mapas devem ser monitorados.
