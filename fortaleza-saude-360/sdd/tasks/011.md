# SDD-011 — Preparar testes unitários

**Fase:** Fundação e UI  
**Status:** pendente  
**Dependências:** SDD-010 concluída; dependências adicionais de dados conforme necessário  
**Arquivos prioritários:** `vitest.config.ts`.

## Objetivo (escopo único)
Configurar Vitest e Testing Library.

## Passos pequenos
1. Ler requisitos aplicáveis e inspecionar somente arquivos da tarefa.
2. Especificar contrato/estado esperado e um teste de falha antes de editar.
3. Implementar a menor mudança que cumpra este objetivo.
4. Rodar testes e revisar impactos em UI, privacidade e proveniência.
5. Atualizar `sdd/STATUS.md` com evidência.

## Critérios de aceite
- npm run test executa teste de exemplo.
- Typecheck/lint/build relevantes passam ou impedimentos documentados com comando e log.
- Nenhum dado fictício disfarçado de dado real; fontes e licenças respeitadas.
- Sem features adicionais não solicitadas nesta microtarefa.

## Prompt para agente
Execute exclusivamente a SDD-011 (Preparar testes unitários), seguindo `AGENTS.md` e `prompts/AGENT_TASK.md`. Antes de codar, detalhe o plano em 3 passos. Termine com diff resumido, testes executados, riscos e atualização do status. Não prossiga para outra tarefa.
