# Contrato para agentes (obrigatório)
1. Ler README, docs/PRD, docs/ARCHITECTURE, docs/DATA_SOURCES e tarefa SDD escolhida antes de codar.
2. Trabalhar **exatamente uma microtarefa** por rodada; não antecipar tarefas dependentes.
3. Apresentar plano mínimo, listar arquivos alterados, evidências de testes, riscos, e atualizar sdd/STATUS.md.
4. Não inventar estatísticas ou endereços de postos. Manter `DEMO` em TODO dado sintético; bloquear produção com mock.
5. Não usar API paga/chave embutida, nem scraping não permitido, nem dados pessoais de saúde.
6. Toda fonte deve ter link, órgão, referência temporal, data de coleta, licença e dicionário no manifesto.
7. Data science: não inferir oferta/capacidade ou gravidade clínica apenas a partir de cadastro; estimativas devem ter incerteza.
8. UX responsiva, teclado e contraste WCAG AA; testes antes de concluir.
9. Nunca remover avisos de limitações ou substituir tempo em rota por distância em linha reta sem rotular.
10. Commit sugerido: `feat(f360): SDD-XXX descrição`.
